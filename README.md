# CodeAlpha Cloud Computing Internship Projects

This repository contains the cloud computing projects developed as part of the **CodeAlpha Cloud Computing Internship Program**.

The repository includes two completed projects focused on **AI-powered interaction** and **data redundancy management**, demonstrating practical application development, frontend/backend integration, data validation, and cloud-oriented system design.

## 📌 Projects

### 1. AI Chatbot

An interactive **AI-powered chatbot application** designed to provide instant responses to user queries through a web-based interface.

#### Key Features

* Interactive chatbot interface
* User query and response interaction
* Frontend and backend architecture
* Predefined chatbot functionality
* Responsive web interface
* Backend API integration
* Environment-based configuration

#### Technology Stack

* **Frontend:** JavaScript, Vite
* **Backend:** Node.js
* **Package Management:** npm
* **Architecture:** Frontend + Backend

#### CodeAlpha Task

**Task 4 — Making a Chatbot**

According to the CodeAlpha task requirements, the project focuses on designing an AI-powered chatbot capable of responding to user queries and integrating the chatbot with a web interface.

---

### 2. Data Redundancy Removal System

A **Data Redundancy Removal System** designed to identify duplicate or redundant data and validate new entries before they are added to the system.

The system focuses on maintaining data accuracy and reducing unnecessary duplicate records.

#### Key Features

* Data entry and validation
* Duplicate data detection
* Redundancy identification
* Validation against existing data
* Prevention of duplicate records
* Unique data management
* Frontend and backend architecture
* Responsive web interface

#### Technology Stack

* **Frontend:** JavaScript, TypeScript, Vite
* **Backend:** Node.js
* **Package Management:** npm
* **Architecture:** Frontend + Backend

#### CodeAlpha Task

**Task 1 — Data Redundancy Removal System**

The CodeAlpha requirements include identifying and classifying redundant data, validating new data against existing records, preventing duplicate entries, and maintaining accurate and efficient data.
